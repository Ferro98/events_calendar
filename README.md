# ☀️ Summer Squad

**Summer Squad** is the ultimate web application to organize group events, plan activities, and coordinate who brings what—ensuring you never run out of ice or end up with three people bringing the exact same beer!

## 🚀 Features

- **Secure Authentication:** User management and email invitations handled entirely by Supabase Auth.
- **Event Management:** Easily create and view upcoming events scheduled for the squad.
- **Calendar View:** A dedicated interface to keep track of all important dates at a glance.
- **Collaborative Checklist ("What are we bringing?"):**
  - Dynamically add items needed for any event.
  - Smart claiming system: locks items already picked by other users and displays their name.
  - Fluid and responsive layout (fully optimized for smartphone use while grocery shopping!).
- **Responsive UI & Dark Mode:** Meticulously crafted user interface built with Tailwind CSS, optimized for both desktop and mobile screens.
